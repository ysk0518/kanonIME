# Samsung キーボードとの差

更新: 2026-11-26。基準のキーボードを Gboard から Samsung キーボード（Galaxy 標準）へ変更した。ユーザーが普段使っているのが Samsung キーボードのため。

参照画像は 2026-11-26 にユーザーが Galaxy 端末で撮ったスクリーンショット（日本語12キー、英語12キー、数字12キー、英語QWERTY、記号2ページ）。画像はリポジトリに含めない（`.local/gboard-ref/`）。Kanon 側は同日の main の実機画面とコード。

画像にない画面（日本語QWERTY、12キーの記号・絵文字画面、フリックの割り当て、長押しの候補）は「要確認」とし、推測で断定しない。

`INPUT_BEHAVIOR.md` の Q1〜Q8 は Gboard を基準に決めた。Samsung キーボードと動きが違う項目が見つかった場合は、別途見直す。

## 区分

- **同等**: Kanon にあり、配置・動きが概ね同じ。
- **差あり**: Kanon にあるが、配置・表示・範囲が違う。
- **なし**: Kanon にない。
- **対象外**: `KANON_SPEC.md` で意図的に除外している、またはオンライン・OS 制約で実現が難しい。

## 次に決めること

優先順位はユーザーと決める。候補は次のとおり。

1. **12キーの配置を揃える**: 左列（↺・←・あa1・🌐）、入力中に「変換」「候補」へ変わる表示、Enter キーの表示、かなキーの数字表示。毎回目に入る部分で、差が大きい。配列キーと記号キーの置き場所を決め直す必要がある。
2. **英語12キー・数字12キーの割り当て**: 1キーの記号、スペースと -# の位置、数字キーの記号の表示と下段。
3. **英語QWERTYの数字の段と最下段**: 数字の段、!#1 キー、URL 欄の / と www.。
4. **記号画面の並び**: Samsung の2ページの並びに揃える。
5. **↺ 取り消しキーと日本語の確定取り消し**。
6. **ケータイ入力**、**学習した候補の削除**、**絵文字パネル**など機能の追加。

日本語QWERTY、12キーの記号・絵文字画面、フリック・長押しの割り当ては参照画像がないため、追加の画像で確認する。
