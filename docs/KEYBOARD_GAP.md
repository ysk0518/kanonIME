# Samsung キーボードとの差

更新: 2026-11-26。基準のキーボードを Gboard から Samsung キーボード（Galaxy 標準）へ変更した。ユーザーが普段使っているのが Samsung キーボードのため。

参照画像は 2026-11-26 にユーザーが Galaxy 端末で撮ったスクリーンショット（日本語12キー、英語12キー、数字12キー、英語QWERTY、記号2ページ）。画像はリポジトリに含めない（`.local/gboard-ref/`）。Kanon 側は同日の main の実機画面と、P40・P41のコードで更新した配置・動作。

画像にない画面（日本語QWERTY、12キーの記号・絵文字画面、フリックの割り当て、長押しの候補）は「要確認」とし、推測で断定しない。

`INPUT_BEHAVIOR.md` の Q1〜Q8 は Gboard を基準に決めた。Samsung キーボードと動きが違う項目が見つかった場合は、別途見直す。

## 区分

- **同等**: Kanon にあり、配置・動きが概ね同じ。
- **差あり**: Kanon にあるが、配置・表示・範囲が違う。
- **なし**: Kanon にない。
- **対象外**: `KANON_SPEC.md` で意図的に除外している、またはオンライン・OS 制約で実現が難しい。

### 日本語QWERTY

参照画像がないため要確認。Kanon は英語QWERTYと同じ配置で、通常欄の句読点が「、。」、l の右に「ー」、未確定なしのスペース表示は「日本語 ␣」。

### 記号画面（QWERTY・12キー共通）

| ページ | Samsung | Kanon |
|---|---|---|
| 1ページ | 1〜0 / + × ÷ = / _ < > [ ] / ! @ # $ % ^ & * ( ) / - ' " : ; , ? | 同じ |
| 2ページ | 1〜0 / ` ~ \ \| { } € £ ¥ ₩ / ° • ○ ● □ ■ ♤ ♡ ◇ ♧ / ☆ ▪ ¤ 《 》 ¡ ¿ | 同じ |
| 4段目の両端 | 1/2 または 2/2 でページ切替、右端は ⌫ | 同じ |
| 最下段 | ABC・🌐・,・スペース・.・Enter | ABC・🌐・,・␣・.・Enter。URL 欄では / と www. を表示 |

記号の並びは同等。Kanon は !?# または !#1 で毎回1/2から開く。ABC と !?# で文字に戻り、🌐 は配列を切り替えて文字に戻る。12キーから数字に切り替えたときの記号は「数字12キー」の表を参照。

### ツールバー

| | Samsung | Kanon |
|---|---|---|
| 並び | ✨（AI）・😊（絵文字）・!?#（記号）・翻訳・クリップボード・設定・⋯ | メニュー・!?#（記号）・設定可能なショートカット・閉じる |

AI・翻訳はオンライン機能のため対象外。絵文字・記号のボタンは「機能」の表を参照。
