# 12キーフリック・英語単語補完

2026-09-28のユーザー追加依頼に対応。日本語と英語は12キーを既定とし、QWERTYも選択できる。システムのライト／ダーク配色を共有する。

## 操作

- 日本語はタップで中央、左・上・右・下のフリックで周囲のかなを入力する。連打は同じかなの繰り返し。
- 日本語12キーは中央の文字だけを表示し、周囲の小さな方向ヒントは表示しない。日英フリックの選択文字をキー上方の固定プレビューに表示する。英語の方向ヒントはフリック中に隠し、選択文字だけを表示する。文字プレビューの表示、フリック感度、QWERTY記号の長押し時間は設定から保存できる。
- `小゛゜`は直前の未確定かなを小文字・濁点・半濁点へ巡回変更する。変換中・部分確定後は変更しない。
- 削除は未確定かな1文字単位。削除キーの長押しで連続削除。
- 削除キーの長押しは最初の250ms後に連続削除を始め、保持時間に応じて次の削除間隔を120msから最短40msへ短縮する。前の削除が完了するまで次を送らず、指を離すかキーが消えたら停止する。
- 「あA1」キーは日本語→英語→数字を循環し、現在の文字を強調表示する。使わない言語は飛ばし、数字専用欄では数字に固定する。左下の配列キーは使用中の日英両方を12キー／QWERTYへ切り替え、言語変更後も配列を保つ。数字モードも維持する。QWERTYの空白キーは空白入力専用。キーボードを閉じる操作は上部の下向きボタンを使う。

## 配列設定

キーボードの設定ボタン、左上のメニュー、またはアプリアイコンから専用設定ページを開く。使用する言語と、各言語で使う12キー／QWERTYを選んで「保存」する。最低1言語は有効にする。初期設定は日本語フリックと英語12キー。英語12キーはタップで各キーの先頭文字、フリックで周囲の文字・数字を入力する。⇧は次の英字を大文字にする。英語QWERTYでは各キーの小さな文字を長押しで入力する。日本語QWERTYの2段目右端には長音符`ー`を配置する。

`common/KeyboardConfig.ets`が配列一覧・既定値・読み込み値の検証を管理する。使用言語と日英共通の配列は`kanonLayoutOrder`としてPersistentStorageへ保存し、最後に使った言語も保持する。旧版の言語別配列は、最後に使った配列に日英を揃えて読み込む。現在の言語を無効にした場合は有効な言語へ移る。日本語未確定がある配列変更は確定が成功した場合にのみ反映する。数字・記号は一時配列として扱う。

設定対応版はビルド・実機へのインストールまで完了。端末がロック中だったため、設定画面の実機操作・保存後の再起動確認は未実施。
- 英語は固定同梱辞書の前方一致による単語候補を最大8件表示。候補タップで残りの文字を挿入する。
- 英語補完の直後は候補バーの「戻す」または削除キーで追加分だけを取り消す。元の入力済み接頭辞と候補を復元する。別の打鍵・カーソル移動・選択変更・入力先変更で取り消しを解除する。「戻す」は照合不成立時に本文を削除しない。削除キーの場合は通常の削除へ戻る。取り消しはカーソル4096単位以内でのみ扱う。

## 実装

- `FlickKey`がタッチ座標の移動方向を判定。途中の文字をキー内に表示し、指を離した時に1文字を送る。キャンセルは入力しない。
- `KanaInput`がかなをMozcのローマ字単位へ写像。`MozcEngine`は単位配列を保持し、かな単位削除・直前かな変更を実行する。
- `EnglishPrediction`は入力中の単語と固定語彙だけをメモリに保持。単語補完はカーソル位置・接頭辞・候補revision・入力先世代を確認する。
- 英語の入力・候補適用・EnterはKanonのイベントキューを通る。入力欄切替や外部選択変更で英語候補を破棄する。
- EditorAdapterの待機操作にも世代判定を追加し、Coordinatorの確定処理の中間でも入力先変更を検出する。

## 制限・未確認

- 英語辞書は小規模な初期語彙。学習・スペル訂正・次単語予測・自動空白挿入はない。
- 英語候補適用はカーソル4096単位以内に限定する。長文やAPI照合不成立時は補完を見送る。
- パスワード欄では英語候補を抑制する実装。今回その欄の実機観察はしていない。
- すべてのフリック方向・濁点／半濁点／小文字、削除長押し、横画面、他アプリの入力欄を網羅した観察は未実施。
