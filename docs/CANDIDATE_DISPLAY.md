# 候補表示

- 外観設定で候補文字サイズ14〜24（標準18）、通常表示1段／2段（標準2段）を保存する。
- 既存の設定レコードに項目がない場合は標準値を補う。保存・変更差分・初期値復元・IMEへの同期は共通の設定経路を使う。
- 設定内のサンプルは保存前でも即時更新する。実際のIMEへの適用は「保存」後。
- 通常表示は横スクロール。2段の場合は候補を前半／後半に分け、上段を左から右へ、上段の最後で下段の左端へ進む。奇数件の場合は上段を1件多くする。候補の幅は文字長に応じ、長すぎる表示は省略する。
- 通常表示の列には表示する候補文字・添字を保持し、それらをForEachのキーにも含める。候補数が変わらなくても、読みの変化で候補文字が変わった列は更新する。列番号だけで古い候補の描画を再利用しない。
- 下向き矢印で一覧へ展開し、上向き矢印で戻る。一覧は文字長に応じて左から詰め、右端で折り返して縦スクロールする。各候補は最大3行まで表示する。
- 変換操作で選択候補が進んだときは、その候補をスクロール先にする。候補のタップ後はキーボードへ戻る。
- 候補欄の高さは候補の有無で変えない。高さ設定はキー領域を基準とし、段数・文字サイズに必要な候補欄の高さを加えてパネル全体を確保する。通常の画面では2段にしてもキーを小さくしない。既存の画面占有上限は維持する。
- 2段分を確保するとキー領域が160vp未満になる画面では1段にする。横画面や低いウィンドウでの優先順位は、候補の段数よりキーの操作領域とする。
- 候補生成・候補ID／revision照合・確定の経路は既存のCoordinatorを使う。

ビルド確認と実機での操作確認は別に扱う。
